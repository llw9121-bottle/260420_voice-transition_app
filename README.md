# 语音实时转录系统 🎙️

> 基于阿里云 AI 的桌面语音识别应用，帮你把录音快速转成结构化文档。
>
> 当前最新版本：**v2.0**（Windows / macOS 绿色版）
>
> Windows 提供两个版本：**云端识别版**（默认）和**本地识别版**（音频不出本机）。

## 🤔 这是什么？能帮我做什么？

这是一个**桌面应用程序**，可以：

- 🎤 打开应用 → 点击开始录音 → 对着麦克风说话 → 实时转成文字
- ✨ 自动整理文本，可以去除语气词、分成自然段落
- 🔍 **独特功能**：自定义"关键行为匹配"，让 AI 帮你分析对话中出现了哪些特定行为（比如会议中的需求提出、问题反馈、决策安排），并自动生成统计表格

**适用场景：**

| 场景 | 用途 |
|------|------|
| **访谈采访** | 实时转录访谈内容，节省后整理时间 |
| **会议记录** | 自动记录会议内容，识别需求、问题、决策 |
| **讲座听课** | 实时转写讲师内容，不错过重点 |
| **语音备忘录** | 想到什么直接说，自动转成文字笔记 |

## ✨ 主要优势

相比其他语音转文字工具，这个应用有什么优势：

1. **🎯 行为分析功能独有** - 你可以定义自己想要识别的行为类型（比如"用户提出需求"、"设计师反馈问题"），AI 会自动在文本中标注，并统计出现频率，生成汇总表格

2. **🖥️ 原生桌面应用** - 打开就能用，不需要浏览器，界面响应流畅

3. **🧑‍💻 新手友好** - 首次启动自动弹出配置向导，直接在界面输入 API Key 就能用，不用手动编辑配置文件

4. **🔒 数据隐私** - 应用没有自有服务器，也不上报使用数据；API Key 只保存在本机。音频与 AI 整理依赖阿里云，具体边界见下方「🔒 数据隐私与高私密场景」

5. **💸 按实际用量付费** - 语音识别按音频时长、行为分析按 token 计费，直接对接阿里云，没有中间商加价

6. **📊 多种导出格式** - 支持 Markdown、Word、JSON 三种格式，满足不同需求

## 🔒 数据隐私与高私密场景

本应用是本地桌面程序，**没有自有服务器，也不收集任何使用数据**：API Key 只写入本机 `.env`，转写稿、会话快照和录音都保存在本地目录。但**语音识别和 AI 整理依赖阿里云服务**，相关数据会发送到云端处理，具体范围见下表。

### 阿里云百炼对数据隐私的官方说明

根据阿里云百炼（Model Studio）公开文档：

- **不会将用户数据用于模型训练**：官方隐私说明写明“绝不会将您的数据用于模型训练”；训练数据披露摘要也说明“除非客户明确同意，否则不会使用客户的业务数据来开发或改进模型”。
- **调用数据仍会按要求存储**：服务协议约定仅在最短必要期限内存储上传的对话数据，目的实现后删除。也就是说，**“不用于训练”不等于“零留存”**。

参考文档：
- [阿里云百炼 - 合规资质与隐私说明](https://help.aliyun.com/zh/model-studio/privacy-notice)
- [阿里云百炼 - 训练数据披露摘要](https://www.alibabacloud.com/help/zh/model-studio/qwen-and-wan-training-data-disclosure)

> 具体的留存期限、数据处理地点和第三方处理范围，以你账号签署的服务协议及百炼控制台的数据管理设置为准。

### 不同整理风格的数据外发范围

| 格式化风格 | 音频是否上传 | 转写文本是否发送给大模型 |
|---|---|---|
| 原始转录 | 是（实时识别） | 否 |
| **清理口语** | 是（实时识别） | **否** |
| 段落整理（未勾选「AI 语义分段」） | 是 | 否 |
| 段落整理（勾选「AI 语义分段」） | 是 | 是 |
| 行为分析 | 是 | 是（含行为定义与引文依据） |

> **本地识别版例外**：使用 `VoiceTranscription-Windows-Local.zip` 时，上表中的“音频是否上传”全部为**否**——音频只在本机转写。但只要使用「AI 语义分段」或「行为分析」，转写文本仍会发送给阿里云百炼。

### 高私密性场景建议

如果访谈内容属于敏感个人信息，或不能被外部公司接收、保存：

1. **优先使用「本地识别版」**（`VoiceTranscription-Windows-Local.zip`）。音频只在本机转写，不上传阿里云，也不需要 DashScope API Key。
2. 在本地识别版中，**推荐使用「段落整理」模式，但不要勾选「AI 语义分段」**。文本清洗和按停顿分段都在本机完成，转写文本同样不会外发。
3. **本地版适合安静、人声清晰的场合**：多人抢话、远场麦克风、强噪声环境下准确率会明显下降。访谈时尽量使用近场麦克风并减少环境噪声。
4. **预留磁盘空间**：压缩包约 210MB，解压后约 300MB；长期录音还需为 WAV 和会话快照预留空间。
5. **不要勾选「AI 语义分段」，也不要直接使用「行为分析」**。这两项功能会把转写全文发送给阿里云百炼。
6. 如果事后确实需要行为分析，**先自行对关键数据脱敏**（姓名、机构、联系方式、地址等），再把处理后的文本单独交给云端大模型分析，不要直接上传完整原文。
7. 关闭「保存原始音频」可减少本机明文留存；对本地磁盘启用系统级加密（BitLocker / FileVault）。
8. **如果仍使用云端识别版**：音频必须上传阿里云；此时至少只开启「清理口语」或「原始转录」，不要启用 AI 功能。若场景要求音频绝对不出本机，请改用本地识别版。

## 🎯 功能亮点

### 核心功能
- **✅ 实时流式识别** - 边录音边识别，结果即时显示，不用等录音结束
- **✅ 暂停/继续录音** - 长时间录音中间需要休息？随时暂停，继续录制同一个文档
- **✅ 持久会话保存** - 录音中每 5 秒保存快照（磁盘繁忙时顺延），暂停时继续自动保存；停止后先保存原文再整理，导出后仍保留会话
- **✅ 网络自动重连** - 网络临时断开后自动恢复，不丢失已转录内容
- **✅ 音频缓冲优化** - 采集、网络发送和音频写盘分别处理，音频队列有容量上限，原始录音持续写盘
- **✅ 后台启停** - 连接和停止在后台执行，界面显示连接中、录音中、暂停、收尾和保存状态；启动失败可直接重试

会话快照保存在项目目录的 `sessions/` 中，包含原文、整理结果、识别设置、行为配置、音频引用及异常记录。启用保存原始音频时，WAV 会持续写入同一目录，停止后另复制到默认输出目录；关闭开关则不生成录音文件。导出、恢复或新建录音均不会删除旧会话，启动时可打开最近一份有效快照，也兼容旧版 `.tmp/` 恢复文件。

网络缓冲默认最多约 30 秒，写盘缓冲最多约 5 秒。断网、缓冲溢出或磁盘异常可能造成转写或录音缺口，应用会提示并将计数、可用的偏移信息写入会话记录；当前尚不支持自动补转写。程序异常退出时，文本恢复到最近一次成功快照，未完成的语义整理不影响已保存原文。

### 文稿审校与会话历史

1. 在顶部「设置」选择麦克风、识别语言与整理风格；需要回听时，在开始录音前启用「保存原始音频」。
2. 结束录音后，工作区提供「原始转录」「整理稿」「对照」三个视图。原始转录只读，整理稿支持编辑、撤销与重做，对照视图高亮变化。短文精确到字符，长文按行比较以控制处理开销。
3. 编辑停顿约 600 毫秒后自动提交本地快照。「保存修订」建立版本；导出、新建录音、切换会话与退出前会收集尚未自动保存的编辑。每个会话保留第一版和最近十九版整理稿，可恢复历史文本。重新整理基于原始转录，并保留之前的整理稿版本；输入未变化时会复用上次行为分析。
4. 右侧「片段」可定位原文，存在 WAV 录音时可从片段前约半秒开始回听；底部播放器支持暂停、停止和拖动定位。播放采用后台流式读取。
5. 右侧「分析」展示行为匹配的模型评分及引文依据。分析输入单独保存，人工编辑整理稿不会改变分析依据；编辑后需要更新分析时，请重新整理。「版本」用于恢复整理稿文本，不回滚分析元数据。
6. 原文、行为配置、模型和提示词版本均未变化时，「重新整理」会复用上次分析结果，避免重复点击产生不同判定；需要新的独立结果时，点击「重新分析」强制重新调用模型。
7. 点击「会话历史」可按标题或完整原文搜索本地记录，并继续修订、回听或导出。历史列表、片段和分析卡片分页显示；窄窗口自动收起侧栏，也可手动展开。

**时间定位限制：**当前片段时间依据音频发送位置及语音活动事件估计，界面以「约」标注，不提供字级对齐。服务响应延迟可能影响句界；音频写入缺口也可能造成回放偏移，应用会提示核查。旧会话没有片段数据时，可使用播放器定位；未保存音频的会话仍可审校文本。

### 长任务反馈与可靠导出

- **整理阶段提示与取消**：整理时显示当前阶段，长文显示分块进度。点击「取消整理」可返回原稿继续审校；取消会阻止后续阶段并丢弃结果，已经发送的远程请求可能仍需等待返回。旧请求结束前会提示稍后重试整理，避免重复提交请求。
- **可核查的 AI 结果**：语义分段分块处理无换行长文，并校验文字是否被删改；异常时回退到本地分段。行为分析校验返回格式、行为名称与评分，引文通过字符映射定位到输入文本。分析请求使用固定种子和较低温度，并在输入未变化时复用上次结果；LLM 判定仍具有随机性，需要新的独立结果时可点击「重新分析」。失败与回退说明会显示在工作区，并随会话及 Markdown、Word、JSON 一起保存。
- **后台导出与覆盖保护**：导出前显示实际文件路径，Markdown 使用 `.md` 检查同名文件；自定义文件名会处理 Windows 保留名称。文件生成在后台执行，导出按钮保持可见，错误后可重试。三种格式均先写同目录临时文件，写入成功后再替换目标；生成或替换失败会保留原文件。
- **慢磁盘优化**：磁盘仍在保存时，连续草稿编辑合并为最新一次自动保存，减少积压；切换会话、新建录音、导出和退出仍会收集最终编辑。

### 文本处理
- **四种格式化风格可选：**
  1. `raw` - 原始转录，原汁原味，不做处理
  2. `cleaned` - 基础清洗，去掉"嗯啊"语气词和重复内容
  3. `paragraphs` - 整理为自然段落
     - 默认快速模式：基于时间戳分割，不消耗 AI 额度
     - 可选 LLM 增强：让 AI 按语义重新分段，段落结构更自然
  4. `behavior_match` - **关键行为匹配**（特色功能）
     - 你定义要识别的行为 → AI 自动识别标注 → 末尾生成统计表格

- **逐步精细化处理**：清洗文本 → LLM语义段落整理 → 行为匹配，三步提升精度
- **超长文本支持**：按自然边界分块，控制单次 AI 请求大小；实际处理能力取决于模型、配置与网络
- **多语言识别**：支持中文、粤语、英文、日语、韩语、德语、法语、西班牙语、俄语

### 行为匹配特色
- 自定义行为：支持添加 4-7 个你感兴趣的行为，每个行为可以写描述
- 内置常用模板：会议分析、求职面试、需求沟通、领导力评估，一键加载
- 配置导入/导出：备份你的配置，在多设备间同步
- 中英双语自动适配：根据识别语言自动选择对应提示词，效果更好

### 用户体验
- 实时录音时长显示，掌握录音进度
- 录音音量可视化，直观判断麦克风输入是否正常
- 红色闪烁录音状态指示灯，一眼看出是否正在录音
- 文本搜索功能，关键词高亮，快速定位内容
- 滚动锁定：锁定自动滚动，方便录音过程中查看历史内容
- 主题切换：支持 System / Light / Dark 三种主题，记住你的选择
- 快捷键支持：空格开始/暂停、Esc 停止、Ctrl+S 导出、Ctrl+B 行为配置
- 默认导出路径记忆：记住你上次选择的导出目录，不用每次都选

### 导出
- 三种格式：Markdown（适合分享）、Word（适合编辑排版）、JSON（适合二次开发）
- 行为匹配结果完整保留：原位标记 + 末尾统计表格

## 🚀 快速开始

### 方式一：使用预编译绿色版（推荐给普通用户，不用装 Python）

> **Releases 是什么？** 是 GitHub 提供的版本发布页面，你可以在这里下载到已经打包好、直接就能运行的程序，不用自己配置环境。

#### Windows 用户

##### 云端识别版（默认，推荐）

1. 打开 [v2.0 Releases 页面](https://github.com/llw9121-bottle/260420_voice-transition_app/releases/tag/v2.0)
2. 下载 `VoiceTranscription-Windows.zip`
3. 解压到独立文件夹（路径尽量不要包含中文；程序会在同目录生成 `.env`、`sessions`、`output`、`logs`）
4. 双击 `VoiceTranscription.exe` 启动
5. 首次启动会弹出 API Key 配置对话框，粘贴 Key 并保存
6. 重启应用后开始使用

##### 本地识别版（音频不出本机）

1. 打开同一个 [v2.0 Releases 页面](https://github.com/llw9121-bottle/260420_voice-transition_app/releases/tag/v2.0)
2. 下载 `VoiceTranscription-Windows-Local.zip`（约 210MB，解压后约 300MB，已内置 SenseVoice 识别模型）
3. 解压到独立文件夹；**`models` 文件夹必须与 exe 位于同一目录**，不要只移动 exe
4. 双击 `VoiceTranscriptionLocal.exe` 启动
5. 无需 DashScope API Key，点击「开始录音」即可转写

本地版限制：

- 支持中文、粤语、英文、日语、韩语；转写结果自带标点
- 识别按语音停顿出句，最终结果通常在停顿后 0.5–1 秒出现
- 「AI 语义分段」和「行为分析」仍使用阿里云百炼，需要 `BAILIAN_API_KEY`
- 未配置百炼 Key 时，本地转写、原始转录、清理口语、按停顿分段均可正常使用
- 建议 4GB 以上内存，预留约 1GB 磁盘空间

#### macOS 用户

1. 打开 [v2.0 Releases 页面](https://github.com/llw9121-bottle/260420_voice-transition_app/releases/tag/v2.0)
2. 下载 `VoiceTranscription-macOS.zip`
3. 解压得到 `VoiceTranscription.app`，建议放到用户目录下的独立文件夹；如果放在 `/Applications` 后无法保存配置，请移到可写目录
4. **首次打开必须右键点击图标 → 选择「打开」**（应用未签名，不能直接双击）
5. 完成一次右键打开后，后续可正常双击启动
6. 配置 API Key 后重启使用

如果遇到 `dyld: Library not loaded` 错误，打开终端执行：

```bash
brew install portaudio
```

> macOS 构建产物由 GitHub Actions 的 macOS 运行器生成，未做 Apple 签名与公证；首次打开需要手动允许。

### 方式二：源码运行（推荐给开发者）

```bash
git clone https://github.com/llw9121-bottle/260420_voice-transition_app.git

```

## 📖 使用指南

### 基本流程

| 步骤 | 操作 |
|------|------|
| 1 | 选择识别语言（默认中文） |
| 2 | 调整 VAD 静音检测时长：<br>- 对话访谈：400ms（默认）<br>- 朗读演讲：1000ms+ |
| 3 | 选择格式化风格（见下文说明） |
| 4 | （可选）如果用行为匹配，点击「行为配置」设置你要识别的行为 |
| 5 | 点击「开始录音」，允许麦克风访问 |
| 6 | 开始说话，实时看转录结果 |
| 7 | 点击「停止录音」结束转录 |
| 8 | 点击「导出」，选择格式保存文档 |

### 录音时长与资源控制

- **单次识别会话**：DashScope 实时识别单会话上限约 30 分钟。应用会在约 20 分钟、且检测到至少 2 秒静音时自动轮替到新会话，前后文本会合并。
- **连续说话**：如果长时间没有 2 秒以上停顿，轮替会等待静音；建议在 20 分钟左右主动停顿 2-3 秒，避免接近服务端 30 分钟上限。
- **总时长**：应用没有总时长硬上限，但长时间录音依赖磁盘空间、网络稳定性和内存占用。建议会议/访谈按 30-60 分钟分段保存。
- **磁盘占用**：16kHz 单声道 WAV 约 115MB/小时；关闭「保存原始音频」可只保留文本和会话快照。
- **网络中断**：应用会自动重连并保留已确认文本；发送缓冲默认最多约 30 秒，超出可能形成转写缺口。
- **暂停**：暂停不会向服务端发送音频，也不会产生额外音频时长；恢复后继续同一会话。

### 行为匹配功能怎么用？

行为匹配是本应用的特色功能，可以让 AI 识别对话中你关心的特定行为。举个例子：

**会议分析场景：** 你定义以下四个行为：
1. **需求提出** - 提出新的需求或需求变更
2. **问题反馈** - 反馈遇到的问题或bug
3. **风险识别** - 指出潜在风险和问题
4. **决策安排** - 做出的决策和行动计划

录音转录完成后，AI 会：
- 在原文中标注哪里出现了哪个行为，给出置信度
- 在文档末尾自动生成统计表格，统计每个行为出现多少次，按置信度分类

**使用步骤：**
1. 格式化风格选择 `behavior_match`
2. 点击「行为配置」按钮
3. 可以选择：
   - 点击「加载模板」选择预置模板一键载入
   - 或者自己手动添加行为名称和描述
4. 保存配置，开始录音
5. 停止后等待 AI 分析完成
6. 导出就能看到带标注和统计表的文档

### 重新整理与重新分析

| 操作 | 行为 |
|------|------|
| **重新整理** | 按当前风格和配置重新生成整理稿。原文、行为配置、模型、提示词版本、AI 分段和分块设置均未变化时，直接复用上次行为分析结果，不再调用模型。 |
| **重新分析** | 忽略上次分析，强制重新调用模型。适合对当前结果不满意、或想获得新的独立判断时使用；同一文本的结果可能不同。 |

补充说明：

- 修改行为定义、描述、示例、模型或 AI 分段/分块设置后，「重新整理」会自动重新分析。
- 人工编辑整理稿不会改变行为分析依据；需要让分析反映编辑后的文本时，请重新整理或重新分析。
- 复用结果会在统计表下方标注；需要新的独立结果时，再点「重新分析」。
- ASR 识别不会因「重新分析」重复计费；重复计费只发生在行为分析和语义分段调用上。

## ⚠️ 注意事项

### 重要操作提醒

- **重新整理 vs 重新分析**：输入未变化时「重新整理」复用上次分析；需要新的独立结果时用「重新分析」。修改行为定义/模型/分段设置后，「重新整理」会自动重跑。
- **行为分析有随机性**：同一文本多次分析可能得到不同引文或置信度；统计表中的频次是“可定位引文数量”，不是绝对行为次数。
- **编辑整理稿不改分析依据**：人工修改整理稿不会自动更新行为分析；需要同步时请重新整理或重新分析。
- **保存音频**：只有启用「保存原始音频」才会生成 WAV，之后才能回听；关闭后仍保留文本和会话。
- **长录音**：应用约 20 分钟自动轮替，服务端单会话约 30 分钟；连续说话时请在 20 分钟左右停顿 2-3 秒。
- **网络与磁盘**：断网可能造成转写缺口；16kHz WAV 约 115MB/小时，请预留磁盘空间。
- **隐私**：API Key 保存在本机 `.env`；默认日志只记录转写长度，不记录完整内容。需要排障时可显式设置 `LOG_ASR_TEXT=true` 或 `LOG_LLM_RAW=true`。高私密场景请先阅读「🔒 数据隐私与高私密场景」章节。

### API Key 相关
- 🔑 **API Key 保存在你本地电脑**，不会上传到其他地方
- 如果需要修改 API Key，主界面右侧设置面板底部有「🔑 设置 API Key」按钮，随时可以改
- 不要把 `.env` 文件提交到公共仓库，已经在 `.gitignore` 中保护你

## 🐛 常见问题

**Q: 双击 exe 没反应？**

A: 请确保完整解压，不要直接在压缩包内双击运行，必须解压到文件夹再运行。

**Q: Windows 提示"已保护你的电脑"？**

A: 这是 Windows SmartScreen 对未签名应用的正常提示，点击「更多信息」→「仍运行」即可启动。

**Q: macOS 提示"无法打开，开发者无法验证"？**

A: 这是 macOS 对未签名应用的安全机制。解决方法：**右键点击图标 → 选择「打开」**，在弹出框点击「打开」。第一次这样操作后，以后就可以直接双击打开了。

**Q: 提示"网络连接失败"？**

A: 检查：
1. 网络是否能正常上网
2. API Key 是否正确输入
3. 阿里云账号是否有余额

**Q: 识别出来文字分段不对/断句太碎？**

A: 调整 VAD 静音检测时长：
- 如果断句太碎，调大 VAD 时长（比如从 400ms 调到 800ms 或 1000ms）
- 如果一句话太长没断开，调小 VAD 时长

**Q: 行为匹配结果不准确怎么办？**

A: 几个建议：
1. 行为描述写清楚一些，给 AI 更多信息
2. 行为数量控制在 4-7 个，不要太多
3. 确保启用了"LLM 段落整理"，先整理段落再匹配精度更高
4. 如果文本很长，确保开启了"自动分块"，避免超长文本上下文稀释

**Q: 为什么同一段文本两次行为分析结果不一样？**

A: LLM 判定本身具有随机性，即使固定种子和较低温度也无法保证逐字一致。应用已做两层处理：

1. 原文、行为配置、模型和提示词版本未变化时，「重新整理」复用上次分析结果，不再调用模型。
2. 需要新的独立结果时点击「重新分析」，或修改行为定义/模型后再整理。

建议把行为描述和示例写具体，并保留「分析模型、分析时间」信息，便于对比不同结果。如果需要在较长周期内复现同一口径，可在 `.env` 中使用带日期的快照模型名，避免 `qwen-plus` 等滚动别名随服务升级发生变化。
